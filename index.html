Rodapé da clínica

Aviso de privacidade e LGPD

Este sistema armazena dados pessoais e dados sensíveis de pacientes neste navegador. Mantenha o computador protegido, faça backup regularmente e use estes dados apenas para a finalidade de atendimento da clínica.

Ao continuar, você declara estar ciente de que os dados ficam salvos localmente neste dispositivo.

Segurança

Digite sua senha para acessar o sistema.

A senha protege contra acesso casual neste navegador. Para segurança forte, use também senha no Windows, backup seguro e versão com backend/criptografia.

Lembretes de amanhã

Confira os agendamentos de amanhã. O botão abre o WhatsApp com a mensagem pronta. Depois de enviar, marque como enviado para evitar duplicidade.

Aniversariantes

Veja aniversariantes de hoje, dos próximos 7 dias e do mês. Use o WhatsApp para enviar uma mensagem de felicitação e marque como enviado para evitar duplicidade no mesmo ano.
